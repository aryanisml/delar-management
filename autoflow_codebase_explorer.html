⚠️ All API keys (Supabase, Cashfree, EmailJS) are currently hardcoded throughout the codebase. Move these to environment variables before going to production.
ℹ️ Two portals: /dealer/... for dealer staff and /admin/... for admin team. Role is determined at login from the user_roles table — not from JWT claims.

/dealer/bookings
DealerBookings — walk-in wizard
loadVehicles()→Step 1. Calls getWalkInVehicles() to show available cars with images and pricing. Filters by the date range the dealer entered.
selectVehicle(vehicle)→Stores selected vehicle in local state, advances wizard to Step 2 (trip details).
updateTrip() / tripInvalid()→Step 2 validators. Checks pickup location, purpose, dates are filled in before letting the dealer advance.
continueToCustomer()→Validates Step 2 and moves to Step 3 (customer lookup/create).
lookupCustomerByMobile()→Step 3. Calls findCustomerByMobile() — auto-fills the form if the customer has booked before.
onIdProofSelected()→Handles ID document upload. Calls uploadCustomerIdProof() — tries Supabase Storage, falls back to data URL.
generateQuotation()→Step 4. The big one — calls createWalkInQuotation() which writes to 4 tables at once (customer, booking, quotation, vehicle). Builds the pricing display.
sendQuote('email'|'sms'|'whatsapp')→Optional Step 4a. Email path: builds PDF → sends via EmailJS → stamps sent_at on quotation. SMS/WhatsApp: opens native link, no DB write.
confirmOfflineCollection()→Records cash advance before admin approval — calls recordOfflineAdvancePayment(). Means when admin approves, booking auto-activates.
confirmBooking()→Step 5. Calls confirmWalkInBooking() — submits quotation, notifies admins, logs audit. Navigates to /dealer/my-bookings on success.

PaymentComponent
ngOnInit()→Calls BookingFlowService.loadBooking() and getPaymentByBooking() to check if payment already exists. Calls buildQuotationPricingPreview() for amounts.
proceedToGateway()→Online payment path: calls createCashfreeOrder() → gets session_id → opens Cashfree SDK checkout widget. After SDK resolves, immediately marks paid and activates booking.
